진단카메라 개인정보처리방침

시행일: 2026년 11월 2일 · 운영: ㈜서현 안전진단본부

진단카메라(이하 “앱”)는 시설물 안전진단 현장에서 사진을 지정한 이름과 번호로 저장·관리하기 위한 업무용 카메라 앱입니다. 앱은 개발·운영자의 서버로 어떠한 개인정보도 전송하지 않으며, 모든 데이터는 사용자의 휴대폰과 사용자가 직접 연결한 저장소(본인의 Google 드라이브, 회사 NAS)에만 저장됩니다.

2. Google 사용자 데이터의 이용

앱은 사용자가 설정 화면에서 「구글 계정 연결」을 선택한 경우에만 Google 드라이브 권한 https://www.googleapis.com/auth/drive.file을 요청합니다. 이 권한으로 앱은 앱이 직접 만든 폴더와 파일에만 접근하며, 사용자의 다른 드라이브 파일은 열람·수정할 수 없습니다.

  • 앱은 사진·동영상·촬영기록 파일을 사용자 본인의 드라이브 “진단카메라” 폴더에 업로드하는 용도로만 이 권한을 사용합니다.
  • Google 사용자 데이터를 개발·운영자나 제3자에게 전송·판매·공유하지 않으며, 광고나 분석 목적으로 사용하지 않습니다.
  • 앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요건을 준수합니다.

3. 제3자 제공 및 국외 이전

앱은 개인정보를 제3자에게 제공하지 않습니다. 다만 사용자가 직접 선택한 경우 다음 서비스로 데이터가 전송됩니다.

  • Google 드라이브(Google LLC): 사용자 본인 계정으로의 업로드
  • 휴대폰의 음성인식·음성합성 서비스: 음성 메모 입력, 사진번호 음성 안내
  • 사용자 회사의 NAS: 사용자가 설정한 주소로의 업로드

4. 보관 및 삭제

  • 사진·동영상은 사용자가 휴대폰에서 직접 삭제할 때까지 보관됩니다. 앱을 삭제해도 사진 파일은 휴대폰에 남습니다.
  • 촬영기록·설정·저장된 NAS 암호는 앱 삭제 시 함께 삭제됩니다. 설정의 「NAS 연결 해제」로도 암호를 삭제할 수 있습니다.
  • Google 드라이브 접근 권한은 Google 계정 > 보안 > 서드파티 앱 액세스에서 언제든 해제할 수 있습니다.

5. 수집하지 않는 정보

앱은 광고 식별자, 연락처, 통화기록 등을 수집하지 않으며, 별도의 이용 통계·분석 도구를 포함하지 않습니다.
